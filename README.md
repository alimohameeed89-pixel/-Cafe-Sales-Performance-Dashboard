# -Cafe-Sales-Performance-Dashboard

☕ Cafe Sales & Performance Dashboard

📊 Project Overview
This dashboard provides a detailed analysis of a cafe's daily operations and sales performance. It tracks key metrics such as total revenue, order volume, and peak hours to help optimize staffing and inventory management.

🚀 Key Features & Insights
Financial Summary: Total sales reached $42.63K with an average transaction value of $32.47.

Order Volume: A total of 1,313 orders were processed across different periods.

Peak Performance: The Afternoon shift is the busiest, accounting for $17K in sales and 521 orders.

Popular Products: Latte and Americano With Milk are the top-performing drinks, contributing significantly to the total revenue.

Payment Preferences: The majority of transactions ($39K) are made via Card, while Cash accounts for only $3K.

🛠️ Tools & Technologies
Power BI: Data visualization and interactive dashboarding.

DAX: Created measures for Average Money, Median of Money, and Total Orders.

Data Transformation: Used Power Query to categorize time periods into (Morning, Afternoon, Evening).

📐 Dashboard Components
KPI Cards: Real-time tracking of Min/Max/Avg sales and total order counts.

Bar Charts: Comparison of sales by payment type and by different drink categories.

Time Analysis: Breakdown of sales and orders by day quarters (Morning vs. Afternoon vs. Evening).

Monthly Trends: A bar chart showing sales volume across different months (May, July, June, etc.).

Gauge Chart: Visual representation of current sales versus the overall target.

📁 How to Use

Download the .pbix file.

Filter the data using the Slicers on the left (Month & Drink types) to see specific performance metrics.
